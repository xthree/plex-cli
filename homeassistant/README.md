# Home Assistant Automations

This directory holds YAML automation files generated by `plex-cli`.

## Generating an automation

**Interactively** — select *🏠 Generate Home Assistant automation* from the main menu:

```bash
plex-cli
```

**From the command line** (scriptable):

```bash
# Movie
plex-cli ha-automation "Inception" --player media_player.plex_living_room

# TV show — resume from On Deck (default)
plex-cli ha-automation "Breaking Bad" --player media_player.plex_living_room

# TV show — always start from S01E01
plex-cli ha-automation "Breaking Bad" --no-resume

# Write to a custom path
plex-cli ha-automation "Inception" --output ~/ha-config/automations/plex_inception.yaml
```

## Importing into Home Assistant

1. **Create a Button helper**
   `Settings → Devices & Services → Helpers → + Create Helper → Button`
   Use the entity ID shown in the YAML comment (e.g. `input_button.play_inception_on_plex`).

2. **Import the automation**
   `Settings → Automations & Scenes → + Add Automation → Edit as YAML`
   Paste the contents of the generated YAML (or point HA at the file via `packages:`).

3. **Verify the `media_player` entity**
   Replace `media_player.plex_player` with the actual entity ID of your Plex media player
   (visible in `Settings → Devices & Services → Plex`).

## How it works

Generated automations use the
[Plex Home Assistant integration](https://www.home-assistant.io/integrations/plex/) and call
`media_player.play_media` with a JSON `media_content_id` that identifies the title by library
name and title (or show/season/episode), so no rating keys need to be hard-coded.

For TV shows generated with `--resume` (the default), the integration plays the On Deck episode —
the next unwatched episode or the episode you were part-way through.
